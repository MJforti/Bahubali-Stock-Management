# Project Rules - Bahubali Enterprises Stock Management

## Deployment Directive
- **Simultaneous Deployments**: Whenever any code tweak, fix, or feature addition is made, immediately commit and push the changes to GitHub (`https://github.com/MJforti/Bahubali-Stock-Management.git` on `main` branch).
- **Vercel Auto-Deployment**: Because the GitHub repository is linked to Vercel, every `git push origin main` automatically triggers a simultaneous production build and deployment on Vercel.
